Universe rendering checks

Run one page at a time in a foreground WebGL2 browser. Each check exercises production rendering code; results appear on the page. These are correctness diagnostics, not app frame-rate benchmarks.

  • Black hole — native-resolution lensing, stars, torus/disc and fixed camera views; paused/animated GPU timing.
  • Cloud depth — 24 terrain/deck and normal/reversed-depth cases.
  • Cloud limb — 12 views covering the original non-finite horizon regression.
  • Surface light — emitted/reflected light, atmospheric transport, seasonal height and program preparation.
  • Volume uploads — actual texel readback, partial slabs, formats and disposal.
  • Galaxy density — 512 CPU/GPU arm-field comparisons; accepts a galaxy seed query.
  • Shader readiness — compare first draws before/after preparing nine nebula carriers.
  • Seasonal surface — controlled visual reference with winter/summer and orbit/ground controls; deliberately generous terrain budget.
  • Ring/cloud depth — foreground visibility, far-side occlusion, and thin-ring transparency in normal and reversed depth.

Save raw output to ignored .artifacts/. Maintained instructions and expected results are in docs/VALIDATION.md.
